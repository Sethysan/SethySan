### 🚀 Featured Project

#### 🍕 Coccia House — Restaurant Website & Management Platform

**Java 21 | Spring Boot | Vue 3 | Pinia | PostgreSQL | Spring Security | Flyway**

🌐 [Visit Live Website](https://cocciahouse.com) | 💻 [GitHub Repository](https://github.com/Sethysan/coccia-site)

An evolving full-stack web platform developed for a family-owned restaurant, combining a customer-facing website with custom administrative and operational tools.

**Key development work:**
- Built and maintained a full-stack application with Vue 3 and Spring Boot.
- Developed RESTful APIs connecting frontend interfaces to PostgreSQL.
- Implemented database-driven menus, pricing, announcements, and weekly offerings.
- Built administrative workflows for creating, scheduling, updating, and archiving content.
- Implemented authentication, authorization, and session-management features using Spring Security.
- Managed database schema changes and migrations with Flyway.
- Improved search performance and frontend responsiveness.
- Designed reusable components to support future business-management features.
- Continued developing features based on real operational needs and user feedback.

**What makes this project meaningful:** It's not simply a portfolio demonstration. It's software used by a real business, where reliability, usability, maintainability, and changing requirements matter.
